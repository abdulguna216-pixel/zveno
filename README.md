# ЗВЕНО — корпоративный сайт

Готовый адаптивный frontend без зависимостей: HTML, CSS, JavaScript, локальные Manrope WOFF2 и 10 уникальных сгенерированных фотографий WebP. Исходное ТЗ сохранено в репозитории.

## Запуск

Требуется Node.js 22+:

```sh
npm run dev
```

Открыть http://127.0.0.1:4173. Статическую папку `dist` можно разместить на любом HTTPS-хостинге. Для проверки обработчика: `npm test`.

## Контакты

На сайте указан телефон для связи и адрес компании. Форма обратной связи удалена. Подготовленный адаптер для Telegram остаётся в `server/leads.mjs` и не используется опубликованным сайтом. Для проверки адаптера: `npm test`.

## Содержание и взаимодействия

Главный экран, услуги, преимущества, этапы работы и галерея направлений. Пункт меню «Направления» ведёт к галерее, «Контакты» — к подвалу. Галерея поддерживает автоматическое движение, паузу, стрелки и сенсорную прокрутку. Есть мобильное меню, клавиатурная навигация и поддержка настройки сокращённого движения.

Система дизайна и применение обязательного скилла: `docs/DESIGN.md`. Промпты и происхождение изображений: `docs/IMAGE-PROMPTS.md`.

## GitHub и Vercel

Исходники: https://github.com/abdulguna216-pixel/zveno

Production: https://zveno-khaki.vercel.app

Vercel публикует папку `dist` без сборки и установки зависимостей. Настройки зафиксированы в `vercel.json`: Framework — Other, Output Directory — dist, пустые Build Command и Install Command. Корень проекта — корень репозитория.

После подключения репозитория к Vercel изменения ветки `main` автоматически публикуются. Переменные и токены Telegram не включены в репозиторий. Серверный Node.js-адаптер сохранён для отдельного размещения.

Оригинальное ТЗ: `ZVENO_website_prompt.md`.
