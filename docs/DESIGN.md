# ЗВЕНО — визуальная система

Обязательный UI UX Pro Max прочитан из https://github.com/nextlevelbuilder/ui-ux-pro-max-skill.
Выполнен поиск `industrial logistics premium B2B --design-system`. Полученный storytelling-паттерн применён; предложенные Liquid Glass и Cormorant не соответствуют ТЗ и отклонены. Уточняющий поиск `industrial minimalism --domain style` вернул Minimalism & Swiss Style: геометричная сетка, свободное пространство, контраст, нейтральный гротеск, мягкие интеракции.

Приоритет у исходного ТЗ: #064E3B, #092C24, #E8D5B5, #F7F1E7, #202724, #FFFFFF; Manrope; асимметрия; чередование светлых и тёмных секций. Отступы 80–140 px, сетка до 1488 px. Карточки 16 px, элементы управления 6 px.

Референсы из ТЗ изучены как источники приёмов, без копирования материалов: damngoodbrands.com (курсор и карточки), sunday.ai (типографика и мягкое движение), teatrion.ru (композиция и ленты), lkstr.ru (промышленная эстетика). Сайты не являются источником текста или изображений ЗВЕНО.

Доступность: видимый фокус, подписи форм и ошибки по полям, aria-live, native dialog, клавиатурная галерея, пауза автоматического движения, prefers-reduced-motion, отключение курсора на сенсорных устройствах. Изображения WebP, собственные шрифты WOFF2, без сторонних frontend-зависимостей.
